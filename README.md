# Avenue-Supermart-Dmart---Financial-Model-and-Valuation
Overview
This project presents a comprehensive Discounted Cash Flow (DCF) valuation of Avenue Supermarts Limited (D-Mart). The model forecasts the company's financial performance, free cash flows, and intrinsic equity value based on historical financial statements and business fundamentals.

Objective
Analyze D-Mart's historical financial performance.
Forecast revenue, operating profitability, working capital, and capital expenditure.
Estimate Enterprise Value and Equity Value using a DCF framework.
Compare intrinsic value with the current market price.

Tools Used
Microsoft Excel
Financial Modeling
DCF Valuation
CAPM
Sensitivity Analysis

Key Assumptions
Revenue Growth
Forecast based on historical trends.
Supported by store expansion plans.
Considered GDP growth, GDP per capita growth, and inflation.
Operating Margins

Gradual improvement due to:
Operating leverage
Scale efficiencies
Supply chain optimization
Higher store productivity

Cost of Capital
WACC: 12.45%
Terminal Growth Rate: 5%

Sensitivity Analysis
The valuation was tested across multiple WACC and terminal growth rate assumptions to assess the impact on intrinsic value.

Key Findings
D-Mart continues to benefit from strong revenue growth driven by store expansion and increasing consumer spending.
Significant value is derived from long-term cash flow generation.
The DCF-derived intrinsic value suggests the stock is trading at a premium to estimated fair value under the model assumptions.
